# Granum Grid media

The launch film and the README screenshots were made by a media studio that mounted the
playground and recorded real interactions. The studio is frozen on the
[`media-studio`](https://github.com/vitaliiznak/granum-grid/tree/media-studio/media) branch,
at the playground as it was on 14 October 2026; `main` no longer builds it.

What stays here, because the README links it:

- [`granum-grid-launch.srt`](granum-grid-launch.srt): the film's captions.
- [`granum-grid-launch-description.txt`](granum-grid-launch-description.txt): its publishing
  description.
- [`MUSIC.md`](MUSIC.md): the soundtrack's source, license, and credit.

The film itself and the screenshots are assets of the `media` GitHub release, not files in
git. The film shows datasets that have since left the playground (the genome, market, and
star catalogs, Bitcoin, and the Performance recording) and long jumps that animated; a
short screen recording of the current playground is planned to replace it.
