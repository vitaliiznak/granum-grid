Granum Grid is a frontend-only React/TypeScript playground for exploring large indexed datasets. Jump to a row, search, compare ranges, and save a bookmark. The UI and navigation run in the browser; the playground needs no Granum Grid backend.

The film uses generated demonstration data. Sampled summaries and partial search are labeled. The playground's Bitcoin and Hacker News examples call external public APIs directly. The repository also includes a separate local HTTP teaching example; it is not a deployed backend. Integrations supply their own data provider.
